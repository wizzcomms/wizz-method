## 14. Vocabulário de origem

> Shard da metodologia desta base. Índice: [`INDEX.md`](INDEX.md) · Sempre carregado junto: [`guardrails.md`](guardrails.md)
> Onde a skill genérica contradisser este shard, **o shard vence**, e isso deve ser dito na resposta.

| Termo | Significado |
|-------|-------------|
| **BidCap / Bitcap** | Limite máximo de lance definido pelo anunciante. Estrutura primária de campanha. "Bitcap" é grafia de transcrição de aula; o termo canônico é **BidCap**. |
| **BO** | Brand Objectives. Modelo alternativo, menos viável sob o Andromeda. |
| **ABO** | Estrutura secundária de campanha; desativar se performar mal. |
| **Andromeda** | Algoritmo do Meta que favorece estabilidade e campanhas de alto desempenho. |
| **ADV+** | Segmentação avançada do Meta, em que a IA escolhe o público. |
| **IC** | Iniciar Checkout. |
| **RPU** | Receita por usuário. |
| **VMO** | Valor médio da ordem (ticket médio). |
| **CPA** | Custo por aquisição. |
| **Break-even** | Ponto onde receita paga o custo. CPA máximo = break-even + 30%. |
| **Transição** | Passagem de uma etapa do funil para a seguinte. |
| **Mismatch criativo** | O criativo promete A e a LP entrega B. |
| **Ressaca de aprendizado** | Janela de até 72h após mexer em checkout ou pixel, com o Meta reaprendendo. |
| **3x bidcap** | Volume mínimo de gasto antes de julgar um criativo. |
| **Hook rate** | Taxa de quem clica. |
| **Hold rate** | Taxa de quem fica. |
| **VSL** | Video Sales Letter. |
| **Cena** | Formato de vídeo estilo novela, não script teórico. |
| **Gancho** | Primeiros 3 segundos do criativo. |
| **Decoy** | Plano isca que faz o principal parecer óbvio. |
| **Empilhamento de valor** | Listar tudo que vem junto antes de mostrar o preço. |
| **Order bump** | Oferta adicional dentro do checkout. |
| **Ancoragem** | Mostrar o preço anterior ao lado do novo. |
| **Reversão de risco** | Garantia que transfere o risco para o vendedor. |
| **Front** | Primeira oferta do funil. |
| **The Esqueleto** | GPT personalizado que gera a estrutura do funil e as páginas em HTML/CSS/JS. |
| **Segunda mente** | Uso de IA para documentar a jornada completa da oferta e manter integridade dos dados. |
| **D+2 / D15** | Prazos de saque (Hotmart: +2 dias; ofertas fora do BR: 15 dias). |
| **Coprodutor / Produtor** | Quem executa vendas e tráfego / quem cria conteúdo e detém autoridade. |
| **Mineração** | Busca ativa de especialistas no Instagram para parceria. |
| **Lead (de VSL)** | Bloco de abertura do vídeo (primeiro minuto a poucos minutos); "vende a visualização". Não confundir com lead = contato. |
| **Microlead** | Primeiros 5s a 1 min da lead (100-300 palavras); o "hook da lead". Testa-se antes de trocar a lead inteira. |
| **Pitch / pós-pitch** | Primeira revelação do preço na VSL / tudo que vem depois (garantia, bônus, FAQ, CTAs). |
| **Mecanismo único** | Ver seção 5.5. No jargão do mercado: problema + solução com nome próprio. |
| **Nome chiclete** | Nome curto e memorável do mecanismo ("truque do X"); Fácil, Hype, Curioso. |
| **Superestrutura** | Prova/elemento que já mora na cabeça do público (Monjaro, "asiáticas não envelhecem") usado como âncora. |
| **Play rate / connect rate** | % que dá play no vídeo / % que chega à página após o clique. |
| **Showrun** | Gravação de tela abrindo o produto por dentro, usada como conteúdo da VSL de low ticket. |
| **BBF** | Perfil de Instagram dedicado à oferta (bio 2 linhas, 3 destaques, story diário). |
| **CBO / Advantage** | Orçamento no nível da campanha / automação máxima da Meta. Complementam BidCap e ABO. |
| **Lateralização / oxigenação** | Multiplicar um criativo (ou oferta) vencedor em variações, uma variável por vez. |
| **Meteórico** | Campanha relâmpago de monetização da base (grupo + oferta com prazo); ROAS ~10, teto baixo. |
| **AOV / LTV** | Ticket médio por pedido (= VMO) / valor total que o cliente deixa ao longo da relação. |
| **Order bump vs upsell one-click** | Oferta no checkout vs oferta pós-compra em 1 clique (só funciona bem no cartão; Pix mata). |
| **Teste seco** | Validar a oferta antes de produzir o entregável (reembolsando as primeiras vendas ou com lista de espera). |
| **Cloaker / spy** | Ferramenta que esconde a página real de bots e concorrentes / espionagem sistemática de anúncios. |
| **Rubrica (Radar)** | Pontuação 0-10 de validação de oferta minerada; nota de corte 6 (ver seção 12.2). |
| **Cowork** | Modo agêntico do Claude Desktop usado no radar de ofertas. |

# Implementation Phases

Carregar ao dividir o plano em fases. Template das 5 fases padrão: Foundation, Static Landing, Motion, 3D/Video (se aplicável), Polish.

## Implementation Phases

Sempre dividir em fases.

**Fase 1 — Foundation**

- setup do projeto;
- Tailwind;
- shadcn;
- tokens;
- typography;
- layout;
- componentes base.

**Fase 2 — Static Landing**

- seções principais;
- copy;
- responsive layout;
- imagens;
- CTA;
- SEO inicial.

**Fase 3 — Motion**

- text reveal;
- section transitions;
- hovers;
- magnetic CTA;
- parallax;
- microinterações.

**Fase 4 — 3D / Video** (se aplicável)

- video hero ou R3F;
- fallback;
- performance;
- reduced motion;
- mobile assets.

**Fase 5 — Polish**

- QA visual;
- accessibility;
- performance;
- analytics;
- deploy;
- bug fixes.

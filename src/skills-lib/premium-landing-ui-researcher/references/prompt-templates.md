### Prompt base para criação de landing page

Use este briefing como base quando o usuário pedir uma landing page completa.

```text
Crie uma landing page completa, premium e estratégica para o seguinte negócio/produto:

[DESCREVA AQUI O NEGÓCIO, PRODUTO, SERVIÇO OU OFERTA]

Público-alvo:
[DESCREVA O PÚBLICO]

Objetivo da página:
[EX: vender, captar leads, agendar reuniões, apresentar serviço, vender produto low ticket]

Oferta:
[DESCREVA A OFERTA]

Diferenciais:
[LISTE OS DIFERENCIAIS]

Tom desejado:
Profissional, moderno, estratégico, sofisticado, claro e orientado à conversão.

A estrutura do site deve incluir:

Header / topo:
- menu sugerido

Hero Section:
- headline forte
- subheadline
- proposta clara
- CTA principal
- sugestão visual

Sobre / Autoridade:
- apresentação do negócio
- construção de credibilidade

Serviços / Produto:
- descrição clara
- benefícios
- diferenciais

Seção de Benefícios:
- ganhos práticos e emocionais

Prova / Credibilidade:
- depoimentos ou placeholders
- números, autoridade ou validação

Quebra de Objeções:
- principais dúvidas respondidas

Seção de Conversão:
- oferta ou chamada para ação
- reforço de valor

FAQ:
- perguntas frequentes relevantes

Footer:
- estrutura sugerida

Escreva todos os textos do site:
- headlines
- subtítulos
- descrições
- CTAs
- textos de apoio
- FAQ
- textos prontos para uso

Também descreva a direção visual e design:
- estilo visual ideal
- cores sugeridas
- tipografia
- layout
- elementos visuais
- sensação que o site deve transmitir

Sugira melhorias de conversão:
- otimizações estratégicas
- testes A/B
- melhorias de UX
- elementos extras que aumentam conversão

EXIGÊNCIAS DE QUALIDADE

A landing page deve ser escrita com base nestes princípios:
- linguagem clara, elegante e orientada à conversão
- estrutura lógica e fluida
- alto valor percebido
- texto convincente sem exageros caricatos
- tom profissional, estratégico e moderno
- foco em resultado e transformação
- copy adaptada ao nível de consciência do público
- equilíbrio entre sofisticação e objetividade

O texto não pode soar:
- genérico
- amador
- superficial
- artificial
- inflado sem substância

Priorize precisão, especificidade e prova sobre adjetivos vagos. Escreva com a clareza de quem domina o assunto.

INSTRUÇÕES ESTRATÉGICAS IMPORTANTES

Trate a oferta low ticket como uma solução valiosa, não como algo "barato".

Use elementos de copywriting, marketing e percepção premium.

Escreva pensando em conversão real.

Sempre que possível, aumente:
- a clareza
- a desejabilidade
- a credibilidade

Evite promessas milagrosas.

Não explique teoria.

Entregue a landing page pronta.

Se faltarem dados, complete com hipóteses estratégicas coerentes.

Use 2ª pessoa: "você".

REGRAS IMPORTANTES

Não seja genérico.

Não explique o que está fazendo.

Entregue como um especialista real.

Use linguagem clara, estratégica e profissional.

Foque em valor percebido e conversão.

RESULTADO ESPERADO

O resultado deve parecer um site premium, estratégico, pronto para implementação, com alto nível de qualidade.

Agora crie o site completo com base nas informações fornecidas.
```

### Prompt para hero section com animação 3D no scroll

Use este prompt quando o usuário pedir uma hero section cinematográfica com vídeo ou animação 3D no scroll.

```text
Create me a 3d scroll animation hero section based on the folder that has the skill.

Here is the video: [COLE A ROTA DO VÍDEO AQUI]

You must put the video inside the repository and tell Claude the exact path.

Also include what your website is about and the contents you want to place on the page.

Crie um site cinematográfico, moderno e altamente visual usando React, Tailwind, Framer Motion, Three.js e React Three Fiber.

O site deve combinar elementos visuais premium, animações fluidas e interações avançadas para transmitir uma sensação de profundidade, tecnologia e sofisticação.

Desenvolva uma página com fundo 3D interativo no tema "Inovação Espacial".

No centro, inclua uma esfera de partículas que reage ao movimento do mouse.

Sobreponha um menu minimalista e um bloco Glassmorphism com a visão da empresa.

Use tons de azul profundo, preto e ciano neon.

Crie uma experiência de storytelling visual com Parallax avançado usando Framer Motion, useScroll e useTransform.

Inclua imagens em preto e branco, textos com destaque em amarelo neon e tipografias deslizando atrás das imagens com máscaras orgânicas.

Adicione uma navegação lateral mostrando o progresso da jornada.

O visual deve seguir uma estética ultra-minimalista inspirada no design suíço.

Use bastante espaço negativo, layout assimétrico, linhas finas de 1px, transições suaves de fade entre seções e visual limpo sem sombras pesadas.

Utilize tipografia forte com Space Grotesk para títulos, Inter/SF Pro para textos gerais e fonte mono para detalhes técnicos.

Inclua uma interface de "Computação Espacial" inspirada no design da Apple.

Use um fundo com gradiente dinâmico e cards Glassmorphism com reflexos internos, bordas brilhantes e profundidade visual.

No hover, os cards devem reagir em 3D seguindo o cursor.

Adicione ícones flutuando em diferentes camadas para criar sensação espacial.

Desenvolva também um componente Three.js com um terreno infinito em wireframe animado por Vertex Shader com ruído Perlin.

O usuário deve conseguir mover levemente a câmera com o mouse.

Use linhas neon azuis sobre fundo preto e adicione fog para criar profundidade e atmosfera futurista.

O site deve ser responsivo, performático e otimizado para mobile, reduzindo partículas e efeitos pesados quando necessário.

A experiência final deve parecer cinematográfica, premium, futurista e pronta para uma marca de tecnologia, inovação ou produto digital de alto valor.
```
